## 🌟 Overview

This portfolio is crafted to provide a cutting-edge, interactive digital experience showcasing projects across **Full Stack Web Development**, **Machine Learning**, **Data Analytics**, and **Systems Engineering**. 

Featuring a deep-space cosmic theme with procedural starfields, 3D geometries powered by Three.js, sleek glassmorphism UI, smooth scroll-triggered animations, an interactive command palette (`Cmd+K`), and a live VS Code-style interactive snippet.

---

## ✨ Features

### 🎨 Design & Experience
- 🌌 **Cosmic 3D Canvas** - Procedural starfield universe background and interactive 3D hero canvas powered by `@react-three/fiber` & `@react-three/drei`.
- 💎 **Glassmorphism UI** - Translucent backdrop-blurred cards, gradient borders, and ambient glow effects.
- 🎭 **Smooth Motion & Micro-interactions** - Fluid section reveals, hover tilts, interactive cards, and cursor effects using `framer-motion`.
- ⌨️ **Command Palette (`Ctrl+K` / `Cmd+K`)** - Quick search navigation modal built with `cmdk` for instantaneous keyboard navigation.
- 💻 **Interactive Code Studio Card** - Syntax-highlighted VS Code style terminal window with developer stats and philosophy.
- 📱 **Fully Responsive** - Flawlessly adapted for ultra-wide monitors, desktops, tablets, and mobile devices.

### 🛠️ Technical Capabilities
- 🏷️ **Dynamic Skills Matrix** - Filterable skill constellations (Languages, Frontend, Backend, Machine Learning, Data Analytics, DevOps).
- 🚀 **Rich Projects Showcase** - Interactive project cards with live demo links, GitHub source repositories, and technology badges.
- ⏳ **Experience & Education Timeline** - Structured chronological career journey with glowing milestones.
- 📬 **Working Contact Form** - Functional contact form integrated with Formspree and direct social contact channels.
- 📄 **Resume Integration** - Instant one-click resume PDF download.
- 🔍 **SEO & Metadata Ready** - Search-engine optimized with `react-helmet-async` for rich social preview cards (OpenGraph & Twitter cards).

## 🛠️ Tech Stack

### Frontend & UI
- **Core:** React 18, JavaScript (ES6+), HTML5, CSS3
- **Build Tool:** Vite 7
- **Styling:** Tailwind CSS 3, PostCSS, Autoprefixer
- **Icons & Typography:** React Icons (`react-icons`), Google Fonts (Poppins)

### 3D Graphics & Animations
- **3D Engine:** Three.js, `@react-three/fiber`, `@react-three/drei`, `maath`
- **Animations:** Framer Motion (`framer-motion`), `react-simple-typewriter`
- **Interactive UI:** `cmdk` (Command Palette), `react-syntax-highlighter`, `react-intersection-observer`, `react-scroll`

### Backend, Data & Tools (Projects Ecosystem)
- **Languages:** Python, C, C++, Java, JavaScript, SQL
- **Frameworks & APIs:** Flask, FastAPI, Node.js, Express.js
- **Machine Learning & Data:** PyTorch, TensorFlow, Keras, Scikit-learn, Hugging Face Transformers, Pandas, NumPy
- **Databases & Cloud:** MySQL, MongoDB, Firebase, AWS, GCP, Vercel, Netlify, Render

## 📦 Getting Started

### Prerequisites
Make sure you have **Node.js** (v18.0.0 or higher) and **npm** installed on your system.

```bash
node -v
npm -v
```

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AsmitBhandari/my-portfolio.git
   cd my-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser to view the application.

4. **Create a production build:**
   ```bash
   npm run build
   ```

5. **Preview the production build locally:**
   ```bash
   npm run preview
   ```
